Why the Greeks column is empty

No Indian broker API returns Greeks. NSE's chain endpoint publishes implied volatility but no sensitivities. So delta, gamma, theta and vega are computed in-process from the premium and IV — which is why the Strike Engine can rank on delta fit at all, and why a provider that drops IV degrades ranking rather than breaking it.

Token life is an architectural constraint

Most Indian broker tokens expire at the next login window, which an unattended engine cannot survive without an automated TOTP flow. A long-lived token, or a provider whose login can be scripted from a TOTP secret, is the difference between a system that runs itself and one that needs someone at a keyboard by 09:00.

Composing a data layer

The adapter interfaces are split by capability, not by vendor, so a working layer can be a paid feed for ticks, a broker for orders and margin, and NSE for the chain. Splitting them is also what lets the failure contract degrade precisely: an incomplete chain blocks options entry without stopping everything else.

Execution gate

spec §16 · all sixteen are mandatory If any mandatory check fails: no order. There is no override path.
HALT

Six checks cannot be evaluated. The gate therefore returns no order.

Risk approval, margin, the daily loss limit, position limits, duplicate-order detection and the kill-switch read all require the Risk Engine and Order Manager, which are interfaces without implementations. The gate is doing exactly what it should: an unevaluable mandatory check is a failed check.

Failure contract

spec §29 Every failure domain resolves to exactly one safe action.
If this failsThe system doesBecause
Market data goes stale NO_NEW_TRADES A decision priced on a stale book is a decision about a market that no longer exists.
Broker connection drops NO_NEW_TRADES + RECONCILE Existing positions must be re-established before anything new is added to them.
Option chain is incomplete NO_OPTIONS_ENTRY Partial chains hide the walls and the liquidity that the structure was chosen on.
Risk engine errors NO_TRADE Risk is authoritative; an unevaluable risk decision is a rejection.
LLM / agent errors CONTINUE_WITHOUT_LLM The intelligence layer is optional by construction. Losing it changes nothing.
Redis is unavailable FAIL_SAFE Working memory is a cache; serving stale state silently is worse than stopping.
Database is unavailable NO_NEW_TRADES A trade that cannot be recorded cannot be reconstructed, reviewed, or learned from.
State reconciliation fails NO_NEW_ORDERS If our position and the broker's disagree, every size calculation is wrong.
